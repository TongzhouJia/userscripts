# Gemini 一键切 Argon 高点

`gemini.google.com` 上按 **Ctrl+Shift+O**：Gemini 自己照常开新对话（这是它自带的键），脚本等页面安静下来，
把模型切成 **4 Argon**、思考等级切成 **高点**，再把光标放回输入框。已经是「Argon 高点」就什么都不点。

## 快捷键

| 键 | 干什么 |
|---|---|
| Ctrl+Shift+O | 新对话 + 切到 Argon 高点 |
| Ctrl+Shift+D | 诊断：把选模型按钮、主菜单、思考等级子菜单的 HTML 存进下载文件夹（`gemini-model-menu-….txt`） |

## 怎么认的

全靠界面上的字，不靠 class：输入框旁边写着「Argon 高点 / 3.8 Flash」这种字、点了会弹菜单的按钮；
菜单里带「Argon」的那项；底下「思考等级」子菜单里的「高点」。改了要认的字就改文件顶部的几个正则。

- 选完模型菜单收不收都行（收了就再点开一次）；子菜单依次试点击、悬停、右箭头。
- Ctrl+Shift+O 不拦给 Gemini；它要是没接这个键，脚本替它 `preventDefault`，免得浏览器开书签管理器。
- 页面要安静 `QUIET_MS`（400 毫秒）才动手、最多等 `MAX_WAIT_MS`（3 秒）。新对话开好后模型又被换回去的话，把这两个调大。
